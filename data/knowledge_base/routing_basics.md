# 路由基础与常见故障

## 路由表基本概念

路由表决定数据包的转发路径，每条路由包含：

- 目的网络与掩码：匹配目标 IP 的范围。
- 下一跳：数据包的下一个转发设备。
- 出接口：数据包从本机哪个接口发出。
- 协议来源：直连（connected）、静态（static）、动态（OSPF/BGP 等）。
- 度量值（Metric）：同一路由多条时选路依据。

## 最长匹配原则

当多条路由都能匹配目标 IP 时，
掩码最长（最精确）的路由优先。

例如目标 `10.10.20.5`：

- `10.0.0.0/8` 与 `10.10.20.0/24` 同时存在时，优先走 `/24`。

## 默认路由

默认路由（`0.0.0.0/0`）是"兜底"路由，
未被更精确路由匹配的流量都走默认路由。
缺少默认路由是"能 Ping 通内网但无法上网"的常见原因。

## 常见路由故障

1. 默认路由缺失：内网通、外网不通。
2. 下一跳不可达：路由存在但转发失败。
3. 路由环路：数据包在两台设备间来回转发直至 TTL 耗尽。
4. 静态路由与动态路由冲突：导致非预期选路。
5. 回程路由缺失：请求能到达对端但响应无法返回（单向通）。

## 排查命令

- 查看路由表：`route print`（Windows）、`ip route`（Linux）、`show ip route`（设备）。
- 路径追踪：`tracert`（Windows）、`traceroute`（Linux）。
- 连通性测试：`ping`，建议同时测试网关、下一跳与目标。
